Repositori ini berisi panduan teknis dan laporan proyek akhir praktikum Jaringan Komputer Lanjut.

## 📄 Dokumen Utama
* 📄 [Modul-Jaringan-Komputer-Lanjut-Project-Akhir.pdf](./Modul-Jaringan-Komputer-Lanjut-Project-Akhir.pdf)

## 📌 Topik & Konfigurasi yang Dicakup
1. **Sistem Operasi & Akses Remote:**
   * Instalasi & Konfigurasi Ubuntu Server (CLI & GUI)
   * Konfigurasi Static IP (`netplan`)
   * Remote Management via SSH

2. **Layanan Server & Transfer Data:**
   * File Transfer Protocol (FTP vs Samba)
   * Web Server (Apache2) & Domain Name System (Bind9)
   * SSL/TLS Certificate Setup

3. **Infrastruktur & Optimalisasi:**
   * Load Balancing menggunakan HAProxy
   * Mail Server Configuration (Postfix & Courier)
   * Network Management menggunakan Router Mikrotik & Winbox
